## Posting tips

- Lead with the **number** (2,652) — it stops the scroll.
- Use **concrete skill names** (Boltz-2, OpenFold) — abstracts don't sell
  the new BioNeMo addition; specific GPU tools do.
- The **Hermes** line is short and newsy — drop it first if the audience
  skews multi-agent.
- **Variant A** is the safest for a "what's new" follow-up post.
- **Variant C** reads best on mobile (shortest line lengths).
